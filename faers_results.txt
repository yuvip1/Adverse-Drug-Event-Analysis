10. INCONSISTENCIES AND UNVERIFIABLE ITEMS
-------------------------------------------
1. The repository has no committed `.pbix` or `.pbip` file. The Power BI
   material is a build guide, DAX template, theme, and CSV export setup.
   Therefore, the six-page dashboard layout is documented/planned, not
   verified as an actual built Power BI report.

2. Ollama summaries are not implemented or evidenced. Do not claim that the
   dashboard provides LLM summaries or name an Ollama model.

3. The generated `docs/RESULTS.md` still contains older roadmap wording that
   describes Streamlit/API work as later work, while the current worktree
   contains Streamlit application pages. Treat `README.md` and the actual
   current source as the newer implementation evidence.

4. `src/cycle_time.py` labels its SQL statistic as an average and comments
   that P50 is unavailable, but the live SQL Server supports
   `PERCENTILE_CONT`; the verified median is 5.0 days. The generated JSON
   does not contain the median.

5. The cycle-time script's printed "overall average" is an unweighted average
   of yearly averages, not the overall report-weighted mean. The verified
   all-report mean is 315.12358333333333 days.

6. `fact_report.date_key` and `fact_report.receive_date_key` are both
   populated from receivedate in the transformation workflow, while their
   names imply different semantics. Reporting services use `date_key`;
   cycle-time analysis uses `receive_date_key`. This is a schema-naming
   limitation, not evidence of two distinct receivedate concepts.

7. The project processes 12,000 reports from one sample file, not the
   complete 370,540-report source-set metadata total and not all 31 files.
   Resume claims must use 12,000 unless explicitly described as source-set
   metadata.

8. The statsmodels logistic regression reports `converged: False`. Use the
   scikit-learn logistic regression and gradient-boosting evaluation metrics
   for predictive claims, and avoid inferential claims from the statsmodels
   odds ratios.

9. The signal results are screening statistics. They use PRR, ROR,
   approximate log-scale confidence intervals, and Yates-corrected
   chi-square; they do not prove causation or incidence.

10. The current Git worktree contains uncommitted and untracked changes.
    The commit dates above describe the Git history, not a clean final release
    commit.
